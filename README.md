# Gemma 4 Developer Agent — Paper Track Submission

Kaggle: https://www.kaggle.com/competitions/gemma-4-developer-agent-paper

Paper-track writeup (max 3,000 words) on agentic software engineering with small, locally runnable models.
Judged equally on Novelty, Quality, Relevance, Verifiability, Clarity (0-5 each).
Deadline: 2026-11-12 23:59 UTC.

## Layout
- `paper/`       writeup draft (Markdown, <=3000 words)
- `experiments/` code to reproduce every number in the paper
- `results/`     raw logs/metrics produced by experiments (only real runs)

Rule for this repo: every number in the paper must trace to a file in `results/`.
